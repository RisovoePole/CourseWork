# CourseWork

CLI-утилита для взаимодействия с базой данных PostgreSQL.

## Возможности

Вы можете:

- создать факультет;
- создать специальность для конкретного факультета;
- создать дисциплину для конкретной специальности и задать ей подробности;
- просматривать всю перечисленную информацию;
- импортировать данные из CSV (с настройкой разделителя):
  - факультеты;
  - специализации для факультетов.

Данные сохраняются локально в Docker volume, которым управляет PostgreSQL.

## Запуск

Для удобного запуска установите [`just`](https://github.com/casey/just).

### Вариант 1: через `just`

```bash
just run
```

### Вариант 2: вручную

Если же не хотите устанавливать - можете прописать команды сами:

```bash
docker-compose up -d #поднимает бд, настраивает окружение для приложения
docker attach app # подключается к stdin сервиса
```

### Остановка

После использования приложения не забудьте:
```bash
docker compose down
```
