## Введение

### Актуальность

Составление комплексного расписания является проблемой уже достаточно давно. Составление расписания вручную в рамках учебных заведений, где есть большое количество групп, кабинетов, и других факторов, влияющих на конечное расписание, требует много времени и качественного планирования. Решение проблемы — автоматизировать составление расписания. Уже сейчас есть продукты цель которых — упростить составления расписания, включая его генерацию.
