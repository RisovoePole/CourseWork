#### 2. Компромисс: Время выполнения vs Качество (на примере medium)

Эти два графика заменяют точечную диаграмму. Рассматривая их в паре, легко определить "победителей" и "аутсайдеров" для сложных размерностей.

Время работы (Скорость):
Видно, что SA — самый быстрый (около 93 мс), CP-SAT и TS работают в пределах 200–280 мс. GA катастрофически отстает, тратя более 3 секунд (3220 мс).
Фрагмент кода

``` mermaid
xychart-beta
    title "Среднее время работы на (medium) (мс)"
    x-axis ["SA", "CP-SAT", "TS", "GA"]
    y-axis "Время (мс)" 0 --> 3500
    bar [93, 217, 275, 3220]
```

Soft-штрафы (Качество):
Сравниваем с графиком времени: сверхбыстрый SA платит за свою скорость ухудшением качества (штраф ~3.0). GA работает дольше всех, но при этом выдает самое худшее качество (штраф ~7.4). CP-SAT и TS показывают лучший баланс — отрабатывают за доли секунды и находят решения с минимальным штрафом (~0.8).
Фрагмент кода

``` mermaid
xychart-beta
    title "Средний Soft-штраф на (medium)"
    x-axis ["SA", "CP-SAT", "TS", "GA"]
    y-axis "Штраф" 0 --> 8
    bar [3.0, 0.8, 0.8,  7.4]
```
