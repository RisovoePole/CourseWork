## 2.5 Сравнительный анализ алгоритмов

* **Поиск с запретами (Tabu Search)**

  * Основной механизм: Детерминированные структуры памяти.
  * Отслеживаемые решения: Один путь решения.
  * Стратегия выхода из локальных оптимумов: Запрещает предыдущие ходы.
  * Сильные стороны: Позволяет избежать бесконечного зацикливания.

* **Имитация отжига (Simulated Annealing)**

  * Основной механизм: Вероятностный критерий принятия.
  * Отслеживаемые решения: Один путь решения.
  * Стратегия выхода из локальных оптимумов: Временно принимает ухудшающие варианты.
  * Сильные стороны: Простая математическая формулировка.

* **Генетические алгоритмы (Genetic Algorithms)**

  * Основной механизм: Эволюционное скрещивание популяции.
  * Отслеживаемые решения: Несколько путей одновременно.
  * Стратегия выхода из локальных оптимумов: Мутации и отбор.
  * Сильные стороны: Отличное разнообразие поиска.
