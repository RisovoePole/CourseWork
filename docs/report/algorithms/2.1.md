# Глава 2. Алгоритмы составления расписания

## 2.1 Генетический алгоритм. (Genetic Algorithm)

### 1. Идея и происхождение

Алгоритм основан на принципах **естественного отбора** и эволюционной теории Ч. Дарвина — «выживает сильнейший».
Изначально метод предназначен для поиска глобального экстремума целевой функции в многомерных пространствах поиска.
Задачи составления расписания (Time Tabling) являются **NP-полными**, что делает невозможным нахождение точного решения методом полного перебора за приемлемое время при большой размерности. ГА позволяет находить **приближенные решения** за полиномиальное время, комбинируя элементы перебора с направленным эвристическим поиском.

### 2. Ключевые компоненты

Базовый словарь алгоритма включает следующие понятия:

* **Популяция:** Множество особей (вариантов расписания).
* **Особь (индивидуум):** Конкретное решение задачи, состоящее из набора хромосом.
* **Хромосома:** Упорядоченная последовательность генов, кодирующая параметры решения.
* **Ген:** Атомарный элемент решения (например, информация об одном занятии).
* **Генотип и Фенотип:** Совокупность генов особи и набор соответствующих им значений параметров задачи.
* **Аллель:** Конкретное значение определенного гена (например, номер аудитории).
* **Функция приспособляемости (Fitness function):** Мера «качества» решения, на основе которой происходит отбор лучших особей.

### 3. Алгоритм работы

Пошаговый цикл итерации выглядит следующим образом:

1. **Инициализация:** Формирование начальной популяции (случайным образом или на основе эвристик).
2. **Основной цикл (поколения):**
    * **Применение операторов:**
        * **Мутация:** Случайное изменение значений генов в хромосомах для поддержания генетического разнообразия.
        * **Скрещивание (кроссинговер):** Обмен участками кода между родительскими особями для создания потомков.
    * **Оценка:** Расчет функции приспособляемости для каждой особи.
    * **Селекция:** Отбор наиболее приспособленных особей в новое поколение по принципу элитарности или случайным образом.
3. **Критерий останова:** Достижение максимально возможного значения функции, стабилизация результата в течение нескольких поколений или выполнение заданного числа итераций.
4. **Выбор решения:** Выбор лучшей особи из последнего поколения.

### 4. Применение к задаче составления расписания

* **Кодирование решения:** В источниках описывается структура, где **ген — это учебное занятие**, включающее неизменяемую часть (учебный поток) и изменяемые части (аудитория, день, время). Предлагаются также **агрегативные модели**, где особь состоит из двух взаимосвязанных хромосом (одна для аудиторий, другая для времени).
* **Жёсткие ограничения (Hard constraints):** Обязательные условия (отсутствие накладок у преподавателей/групп). Они учитываются через введение **штрафных коэффициентов** с максимальным весом в целевой функции или путем ограничения диапазона допустимых значений генов при их формировании.
* **Мягкие ограничения (Soft constraints):** Рекомендательные условия (отсутствие «окон», пожелания преподавателей). Учитываются в целевой функции с меньшими весовыми коэффициентами.

### 5. Сложность и эффективность

* **Сложность итерации:** Основные затраты времени приходятся на расчет функции приспособляемости (проверку ограничений).
* **Рост размерности:** В отличие от точных методов, ГА не показывает мгновенного экспоненциального роста времени, но требует увеличения популяции для сохранения качества. **Агрегативные алгоритмы** позволяют замедлить рост временных затрат в 2–3 раза по сравнению с обычными ГА.
* **Сходимость и локальный оптимум:** Существует риск преждевременной остановки из-за недостаточного разнообразия популяции. Для избежания этого применяются высокие вероятности мутации и специальные методы селекции.

### 6. Преимущества и недостатки в контексте расписания

**Преимущества:**

* Поиск приемлемого решения в условиях огромной размерности.
* Возможность гибкой настройки весов различных ограничений.
* Получение сразу нескольких вариантов расписания на выбор.
* Работа в реальном времени: решение можно получить на любой итерации.

**Недостатки:**

* Нет гарантии нахождения глобального оптимума.
* Зависимость результата от качества начальной популяции.
* Высокая вычислительная трудоемкость на поздних этапах поиска.
* Риск застревания в локальном оптимуме при неудачных операторах мутации.

### 7. Примеры использования

* Программный комплекс **«Феб»**, использующий агрегативные ГА для систем массового обучения (разработан Г.Ф. Низамовой).
* Автоматизированная система на основе ГА для **ВКТУ им. Д. Серикбаева**.

### 8. Вывод

Генетический алгоритм является мощным инструментом метаэвристического поиска, который лучше всего подходит для сложных организационных задач типа составления расписания в вузах. Его эффективность напрямую зависит от **правильной формулировки функции приспособляемости** и использования модифицированных операторов, учитывающих специфику связей между объектами (преподаватель — группа — аудитория).
